I've started and abandoned about four blogs before this one, so I'm not going
to pretend this is some grand new chapter. It's a notebook. I wanted a place
that's entirely mine — no algorithm deciding who sees it, no character limit,
no feed pressure — where I can write about the stuff I actually think about
day to day.

That's going to be a mix of things:

- **Code** — things I learn while building, debugging, or arguing with a
  compiler at 1am.
- **Tech** — broader thoughts on tools, products, and the industry, written
  by someone who uses this stuff rather than sells it.
- **Sports** — mostly basketball and whatever tournament has hijacked my
  attention that month.
- **Life** — everything that doesn't fit neatly into the other three.

Each post gets tagged with one of those, and you can filter by topic right
from the home page if you only care about one of them.

## Why static, why now

The site itself is a small flex of the "code" category: it's a Jekyll site,
hand-themed, hosted for free on GitHub Pages, and deployed automatically
through GitHub Actions every time I push to `main`. No CMS, no database,
no monthly bill. Just Markdown files in a folder.

If you want to see how a post is structured, this file is a good example —
it's just front matter and prose. That's the whole system.

Thanks for stopping by. More soon.
